# Plan 04-05: Intercept LangGraph Tool Events

## Objective
Enable zero-latency map updates by streaming the agent and intercepting tool execution messages in real-time.

## Step-by-Step Implementation

- [ ] 1. In `agent.py`: Remove the `structured_llm` wrapping. Change `get_resilience_agent()` to return the raw `create_react_agent` executor.
- [ ] 2. In `agent.py`: Update the Commander's tools to use `tg_tools` directly (flattening the sub-agents so `app.py` can see the internal tool calls like `find_single_point_of_failure`).
- [ ] 3. In `app.py`: Refactor the chat execution block to use `executor.stream({"messages": [("user", user_input)]}, stream_mode="updates")`.
- [ ] 4. In `app.py`: Inside the loop, check if the `update` contains a `tools` chunk (which indicates a `ToolMessage` was appended to the state). If the tool is `find_single_point_of_failure` or `calculate_blast_radius`, parse its JSON output, update `st.session_state`, and instantly push to `map_container.pydeck_chart()`.
- [ ] 5. In `app.py`: If the `update` contains an `agent` chunk with an `AIMessage`, stream its content to the chat UI using `st.write_stream()` or just accumulate and write it.
